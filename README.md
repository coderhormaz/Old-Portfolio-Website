# Old Portfolio Website

An earlier version of my personal portfolio as a full stack developer, built with Next.js and a 3D / animated front end. It has since been superseded by the current Portfolio repository.

## Features

- Portfolio pages showcasing projects and skills
- 3D elements built with Three.js and React Three Fiber
- Scroll and interface animations with GSAP and Framer Motion
- Contact form powered by Web3Forms
- SEO setup with sitemap

## Tech Stack

- Next.js 15, React 19, TypeScript
- Tailwind CSS 4
- Three.js / React Three Fiber
- GSAP, Framer Motion
- Web3Forms (contact form)

## Getting Started

Prerequisites: Node.js and npm.

```bash
npm install
npm run dev
```

Create a `.env` file based on `.env.example` and fill in your own values before running the app — the contact form needs its access key configured there. Never commit your real `.env` file.

Then open http://localhost:3000 in your browser.
